ABOUT & ACADEMIC DEFENSE

Essential theoretical insights justifying the choice of Logistic Regression and mathematical cross-entropy minimization.

  1. Strict Convexity: The Binary Cross-Entropy loss surface has zero local minima, mathematically guaranteeing convergence to the global optimum via Gradient Descent.
  2. Sub-3ms Inference: Runs in microseconds on commodity CPUs without GPU acceleration, indispensable for carrier-grade SMS gateway filtering.
  3. Mathematical Transparency: Log-odds linear decomposition $\ln(p / (1-p)) = w^T x + b$ allows precise token-level accountability for every classification decision.

The linear sum $z = w^T x + b$ spans $(-\infty, +\infty)$. The Sigmoid activation $\sigma(z) = \frac{1}{1 + e^{-z}}$ smoothly maps the unbounded real line into the strict probability interval $(0, 1)$. Our scratch implementation clips $z \in [-500, 500]$ to eliminate floating-point overflow.

In spam filtering, class imbalance (86.6% ham vs 13.4% spam) creates asymmetric risk. Lowering the decision threshold from 0.50 to 0.35 increases spam recall from 89.6% to 93.75%, intercepting high-risk phishing vectors while retaining 96.77% precision.
